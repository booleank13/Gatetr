# Gate.tr Playable Ad

This is a 320x480 interstitial playable ad for Gate.tr.

## Assets
- Images are located in `assets/`.

## How to Run
Simply open `index.html` in a web browser. Use mobile emulation mode (Developer Tools -> Toggle Device Toolbar) with dimensions 320x480 for the best experience.

## Gameplay
- Collect falling cryptocurrencies (Bitcoin, Ethereum, Tether) in the basket.
- Move the basket by dragging (mouse or touch).
- Goal: Reach 200 points in 10 seconds.
- Reward: Redirect to Gate.tr signup page.
